# Brand material: index

All of this is repository material. None of it is served by the site (`brand/` and `docs/` are blocked by `middleware.js` and left out of the deployment by `.vercelignore`), and there is no /brand page. Paths are relative to the repository root.

| Path | What it is | When to use it |
|---|---|---|
| `docs/brand/BRAND.md` | The brand guide: idea and positioning, logo rules (the hound is the only mark, the door rule), colour, type, visual language, motion, tone of voice and hard limits, video guidelines, the AI image and video prompt kit (style block, negative constraints, 10 scene prompts), 12 content series, and the one-page brand prompt. | Before writing or designing anything for Citehound; whenever you brief an AI tool. |
| `brand/brand-prompt.txt` | The one-page brand prompt as plain text, ready to paste. | Paste into any AI text, image or video tool to get on-brand output. |
| `brand/brand.json` | Machine-readable tokens: colours (hex), type families and weights, spacing, radius, motion durations and easing, logo rules, voice limits, video specs. | When a script or tool needs the values; the colours must equal `styles.css` (checked by `scripts/test-brand.js`). |
| `brand/logo/` | The logo set: SVG (mark, horizontal and stacked lockups, wordmark, badge, favicon in full colour, dark, one-colour and white) and `png/` exports at standard sizes. A copy of `assets/brand/`, refreshed by `node scripts/generate-brand-assets.js copy`. | Slides, documents, partners, anything that needs the logo. |
| `brand/social/` | The social asset pack (X, LinkedIn, YouTube, GitHub, Product Hunt, post, story and thumbnail templates) and its README with sizes, sources and where each file is uploaded. | When you set up or refresh a profile or make a post image. |
| `brand/listing-icons/` | 512 and 1024 px square icons for directory listings, and a README saying where each is uploaded. | When you submit or update a listing. |
| `docs/redesign/logo-options.png` | The three logo options (A faithful trace, B geometric, C badge) and why B was chosen. | To see the logo decision. |
| `docs/redesign/` | The redesign notes (`BRIEF.md`, `PROGRESS.md`) and before and after screenshots. | For the history of the design. |
| `assets/brand/` | The site's own copy of the logos, favicon, manifest icons and share images (`og-*.png`). | Never edit by hand: regenerated by `scripts/brand/build_logo.py`, `scripts/generate-brand-assets.js` and `scripts/generate-og.js`. |
| `scripts/brand/`, `scripts/generate-brand-assets.js`, `scripts/generate-og.js`, `lib/og.js` | The generators (logo SVG, PNG set, social pack, share images) and the table of which page gets which share image. | To change a template or regenerate an image. |
