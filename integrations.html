Integrations

Where you can use Citehound

Seven ways to use Citehound are available now. They measure AI readiness: crawler access and on-page signals. The score does not measure whether any assistant names a brand.

Available

Available now.

  • Claude connector

    Add the Citehound MCP server to Claude, Claude Code, Cursor or VS Code. Free and read-only, no account.

  • MCP Registry listing

    The Citehound MCP server is published in the MCP Registry, with its 13 read-only tools described on the MCP page.

  • GitHub Action

    The official Citehound GitHub Action scans a domain from a workflow and can fail a build when the score is below a number you set.

  • Public API

    A JSON API with an OpenAPI description: scan, compare, crawler access and generated files with a free key, and monitoring, the fix list and exports on Pro, Fix and Beyond.

  • Command-line tool

    Scan a domain, compare two sites and generate llms.txt, robots.txt and JSON-LD from a terminal or a build. No account and no dependencies; an API key is optional.

    npx citehound scan yourdomain.com

  • n8n node

    Nodes for n8n to scan, compare, generate files and read monitoring events, with a polling trigger. It is a community node: it has not been through n8n's own review. An API key is needed; a free one is sent by email.

    Settings → Community Nodes → n8n-nodes-citehound

  • Claude plugin

    Adds the Citehound MCP server and three guided skills (scan a site, fix AI crawler access, compare with a competitor) to Claude. It installs from our own GitHub marketplace, andacuzel/cited-geo-guide, not from Anthropic's plugin directory.

    Claude desktop app: Plugins → Add → marketplace "andacuzel/cited-geo-guide" → install "citehound"

    Claude Code: /plugin marketplace add andacuzel/cited-geo-guide, then /plugin install citehound@citehound
