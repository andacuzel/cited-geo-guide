Claude connector

Ask Claude about your site’s AI readiness

Citehound’s connector lets Claude scan a domain’s robots.txt, llms.txt, sitemap and homepage, then generate the files that close the gaps. It is free and read-only, and it needs no account.

Connect it

Add the server address to Claude.

No key, no account. This is the address of the Citehound MCP server.

Claude on the web and desktop

  1. Open Customize, then Connectors.
  2. Click + Add, then Add custom connector.
  3. Enter the name Citehound and paste the server address from above. Click Continue.
  4. If Claude shows an authentication setting, choose No sign in. Citehound needs none. Then click Add.
  5. In a chat, click the + button at the lower left, open Connectors and switch Citehound on for that conversation.

On Team and Enterprise plans an owner adds the connector first, under Organization settings, Connectors, Add, Custom, Web. Members then open Customize, Connectors and click Connect.

Claude Code

Run this once in a terminal, then check the connection with claude mcp list, or type /mcp inside a session.

Terminal 
claude mcp add --transport http citehound https://getcitehound.com/api/mcp

Cursor

Add this to .cursor/mcp.json in a project, or to ~/.cursor/mcp.json to use it in every project.

.cursor/mcp.json 
{
  "mcpServers": {
    "citehound": {
      "url": "https://getcitehound.com/api/mcp"
    }
  }
}

VS Code
  1. Open the Command Palette and run MCP: Add Server.
  2. Choose HTTP (HTTP or Server-Sent Events).
  3. Paste the server address from above, then enter a server ID, for example citehound.

Limits

What it does not do.

The connector measures readiness: whether crawlers can reach a site and whether its pages carry signals a model can read. It does not measure whether any assistant names a brand. It has no Pro or signed-in layer yet.

Questions

Before you connect.

Is it free?

Yes. All 13 tools are free, with no account and no key. The tools that scan a live site are limited per domain, so one site is not fetched over and over. Claude’s own plan decides how many custom connectors you can add: the Free plan allows one.

Does it store anything?

Nothing about who you are. The server keeps short-lived counters keyed by a one-way hash of the scanned domain, which expire within an hour, to limit repeated fetches of one site.

What data does it send?

Claude sends Citehound the arguments of each tool call, such as a domain or a category name. The three tools that scan a live site (scan_site, compare_sites and generate_schema) fetch that domain’s public robots.txt, llms.txt, sitemap and homepage. The other 10 read Citehound’s own files and fetch nothing.

Which clients work?

Claude on the web and desktop, Claude Code, Cursor and VS Code are covered above. Another client that supports remote MCP servers over HTTP can use the same address. In Claude, Team and Enterprise owners add a custom connector for the organization first, then members connect to it.
