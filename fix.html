What we fix

The technical layer the score measures.

  • Schema

    Organization, WebSite and content markup, so machines can tell who you are.

  • robots.txt

    Clear rules for the AI crawlers, set the way you decide.

  • llms.txt

    A short file that says what the site is and where its main pages are. It is optional and low-cost, and nobody has shown that it changes what Google does.

  • Sitemap

    Declared in robots.txt and listing the pages that matter.

  • Titles

    One clear title for each page.

  • Descriptions

    One meta description for each page, written for that page.

Questions

Before you ask.

If nobody can promise a citation, why pay?

No one can guarantee what an assistant says, including us. What we control is whether you are eligible: a site that blocks crawlers, can’t be read or doesn’t answer the question never gets considered. We close those gaps and measure the result: before/after scores, and a citation check each month.

What does Fix change on my site?

The technical layer the score measures: schema markup, robots.txt, llms.txt, the sitemap, page titles and meta descriptions. We agree with you which gaps to close first.

Does Fix write my content?

No. Fix covers the technical layer. Writing and editing content is Citehound Beyond.

Do I need to buy Pro separately?

No. Fix and Beyond both include Citehound Pro.
