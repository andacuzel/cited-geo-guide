Integrations

Where you can use Citehound

Four ways to use Citehound are available now. They measure AI readiness: crawler access and on-page signals. The score does not measure whether any assistant names a brand.

Available

Available now.

  • Claude connector

    Add the Citehound MCP server to Claude, Claude Code, Cursor or VS Code. Free and read-only, no account.

  • MCP Registry listing

    The Citehound MCP server is published in the MCP Registry, with its 13 read-only tools described on the MCP page.

  • GitHub Action

    The official Citehound GitHub Action scans a domain from a workflow and can fail a build when the score is below a number you set.

  • Public API

    A JSON API with an OpenAPI description: scan, compare, crawler access and generated files with a free key, and monitoring, the fix list and exports on Pro, Fix and Beyond.
