Good to know

What this page does.

Where does my key go?

It is held in this page’s memory and sent, as a Bearer token, to this site’s /v1 API with each request. It is not written to localStorage, sessionStorage, a cookie or the address bar. Closing or reloading the page forgets it, and so does the button “Forget this key”.

What does it scan?

The homepage, robots.txt and llms.txt of each watched domain, not the whole site. The score is a readiness score: crawler access and on-page signals. It does not measure whether any assistant names a brand.

Do these requests count against my limits?

Yes. Each action here is an API request, so it counts toward the hourly and daily limits of the key, and adding a domain counts as a scan of that domain.
