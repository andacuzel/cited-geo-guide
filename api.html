API v1

Scan and generate from your own code

A JSON API for the Citehound scan. It scores one page of a domain out of 100 for AI readiness, lists the fixes, shows the state of ten AI crawlers, compares two sites, and writes llms.txt, robots.txt and JSON-LD. The score measures readiness, not whether any assistant names a brand.

Get a key

A free key, by email.

Free keys allow 20 requests an hour and 100 a day. The key is in the email and is shown once.

The key email is transactional and carries no marketing. We store a one-way hash of the key and of your address, plus the masked address. We keep your address itself only if you tick the box. Every key email has a link that revokes the key. See the privacy page.

Quick start

Send the key in a header.

Use Authorization: Bearer <key>, or X-Citehound-Key: <key>. Keep the key out of URLs and public code.

curl 
export CITEHOUND_KEY=chk_your_key_here
curl "https://getcitehound.com/v1/scan?domain=example.com" \
  -H "Authorization: Bearer $CITEHOUND_KEY"

The full description is a machine-readable OpenAPI 3.1 file: /openapi.yaml.

POST /v1/keys Get a free API key by email

Sends a free key to the address. The key is in the email and nowhere else: never in this response. The answer is the same whether or not the address could be given a key. The key email is transactional only; set marketing_optin to true only if you want occasional product updates.

No key needed. Answers 202, 400, 413, 415, 429, 502, 503.

Send JSON with Content-Type: application/json.

Request body 
{
  "email": "you@example.com",
  "marketing_optin": false
}

curl 
curl -X POST https://getcitehound.com/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com"}'

Example response 
{
  "status": "accepted",
  "message": "If this address can receive a key, it is on its way. The key is sent by email only and is shown once."
}

GET /v1/generate/llms-txt Generate an llms.txt

Builds an llms.txt from a name, a one-sentence description and up to 20 pages. Pure text generation: nothing is fetched. Pass each page as "page=<url>|<description>", repeated, or use POST with JSON. llms.txt is an optional convention with no demonstrated effect on Google.

Needs a key. Answers 200, 400, 401, 403, 429, 503.

Query parameters of GET /v1/generate/llms-txt
ParameterRequiredWhat it is
nameYes
descriptionYes
pageNoRepeat for each page, as "<url>|<description>".

A POST to the same path takes the same fields as a JSON body.

curl 
curl -G https://getcitehound.com/v1/generate/llms-txt \
  -H "Authorization: Bearer $CITEHOUND_KEY" \
  --data-urlencode "name=Example Co" \
  --data-urlencode "description=Project software for small design studios." \
  --data-urlencode "page=https://example.com/pricing|Plans and prices"

Example response 
{
  "type": "llms.txt",
  "content": "# Example Co\n\n> Project software for small design studios.\n\n## Pages\n- [Plans and prices](https://example.com/pricing)"
}

GET /v1/generate/robots-txt Generate an AI-crawler robots.txt

Builds a robots.txt that explicitly allows or blocks named crawlers from the ten Citehound tracks, with an optional Sitemap line. Pure text generation: nothing is fetched. Names are comma-separated in the query; POST accepts JSON arrays.

Needs a key. Answers 200, 400, 401, 403, 429, 503.

Query parameters of GET /v1/generate/robots-txt
ParameterRequiredWhat it is
allowNoComma-separated crawler names to allow.
blockNoComma-separated crawler names to block.
sitemapNo

A POST to the same path takes the same fields as a JSON body.

curl 
curl -G https://getcitehound.com/v1/generate/robots-txt \
  -H "Authorization: Bearer $CITEHOUND_KEY" \
  --data-urlencode "allow=GPTBot,ClaudeBot" \
  --data-urlencode "block=Bytespider"

Example response 
{
  "type": "robots.txt",
  "content": "User-agent: GPTBot\nAllow: /\n\nUser-agent: Bytespider\nDisallow: /\n\nSitemap: https://example.com/sitemap.xml",
  "allow": [
    "GPTBot"
  ],
  "block": [
    "Bytespider"
  ],
  "sitemap": "https://example.com/sitemap.xml"
}

Limits

What a key can do.

Every answer carries X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset. When a limit is reached the answer is 429 with a Retry-After header.

Limits of the Citehound API
LimitAllowedNotes
Free key20 requests an hour100 requests a day (UTC)
Pro key200 requests an hour2000 requests a day (UTC)
One domain, all keys together4 scans an hourCounts scans, compare, crawlers and schema
One network address120 requests an hourAcross all keys
Asking for keys5 an hour5 a day for one address

Counters expire on their own within a day. Acceptable use: scan sites you have a reason to look at, keep to the limits, and do not use the API to probe private networks. A key that is abused is revoked.

Errors

Errors are JSON.

Every error has the shape {"error": "code", "message": "…"}. A 429 adds retry_after and limit_scope.

Errors of the Citehound API
StatusCodeMeaning
400invalid_requestThe request is not valid: a missing or malformed parameter.
401invalid_keyThe key is missing or not valid. A WWW-Authenticate header says how to send it.
403key_revokedThe key has been revoked.
404not_foundNo such category or endpoint.
413too_largeThe request body is larger than the limit.
415unsupported_media_typeSend JSON with Content-Type: application/json.
429rate_limitedA limit was reached. The Retry-After header gives the seconds to wait; the body names the limit.
502scan_failedThe scan could not read the site (robots.txt or the homepage), or the key email could not be sent.
503not_configuredThe API is not configured on this server, or its storage is unavailable.

Scope

What it does not do.

The API measures readiness: whether crawlers can reach a site and whether its homepage carries signals a model can read. It does not measure whether any assistant names a brand, and the benchmark is our own archive of scans, dated as shown. It is read-only: it changes nothing on a scanned site. Browser calls from other sites are not allowed (no cross-origin access), so call it from a server.

Questions

Before you build.

What does the score mean?

It is a readiness score out of 100: whether AI crawlers can reach the site and whether its homepage carries signals a model can read. It does not measure whether any assistant names a brand. The same score appears in the web scan and the MCP server.

What does a scan read?

The public robots.txt, llms.txt, sitemap declaration and homepage of the domain you name, through the same guarded fetch as the web scan. One page, not the whole site. The API never sends your key, your address or any credential to the scanned site.

What do you keep about a key?

A one-way hash of the key, a one-way hash of your address, the masked address shown by /v1/me, the plan and the dates. Your address itself is kept only if you tick the update box. Counters for the limits expire within a day. The key email is transactional only.

Can I revoke a key?

Yes. Every key email has a link that revokes that key with one click. A revoked key answers 403 from then on.

Is there a paid plan?

The API has a pro plan with higher limits. It is set by us for a key, and there is no checkout for it yet. Write to hey@getcitehound.com to ask.
