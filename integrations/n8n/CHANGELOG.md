# Changelog

## 0.1.1

- **Scan a Domain** adds a `next_step` field to the result on the Free plan: "Watch this domain weekly and get alerts: Pro. Ready-to-paste fixes: Fix. See https://getcitehound.com/pricing". Paid plans never get it, and nothing is added when the plan cannot be read. The new **Plan Hint** option (on by default) turns it off.

## 0.1.0

First version: the Citehound node (scan, compare, crawlers, benchmark, generators, monitoring, fixes, export, plan) and a polling trigger for monitoring events.
