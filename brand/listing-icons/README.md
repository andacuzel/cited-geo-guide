# Listing icons

Square PNG icons of the Citehound hound (the only brand mark), generated by `scripts/generate-brand-assets.js` (group `listing`). Nothing is uploaded for you.

| File | Use |
|---|---|
| `citehound-icon-512.png`, `citehound-icon-1024.png` | The standard icon: white hound on an ink square, full bleed. Use it wherever a directory takes one square image and rounds or masks it itself. |
| `citehound-icon-rounded-512.png`, `citehound-icon-rounded-1024.png` | The same with rounded corners and a transparent outside, for places that do not round the corners. |
| `citehound-icon-light-512.png`, `citehound-icon-light-1024.png` | Ink hound on the paper colour, for light listings. |
| `citehound-hound-transparent-512.png`, `citehound-hound-transparent-1024.png` | The ink hound alone on a transparent background. |
