How a run works

We keep a fixed set of buying questions for each vertical. They are the questions a buyer asks before choosing a product: the best tool for a team of a given size, which ones connect to an app you already use, what to pick on a budget. None of them contains a brand name, so a brand either appears in the answer or it does not.

Each question goes to one model five times, with no memory carried between runs. For every answer we record two things: whether your brand is named, and whether it is featured. Featured means named in a heading, a list label, a table or bold text, rather than only inside running prose.

Named and featured differ because a name can sit inside a dismissive aside. A line such as “teams outgrow basic tools like X” names X and does not recommend it. In the sample, 3 of the 44 answers that named the brand did so without featuring it. The matrix draws those as rings, not solid dots.

Why five runs

Ask a model the same question twice and the answers differ. One run can show you named or not named by chance, so a single run is never reported as a finding.

In the sample, 5 of 18 questions named the brand in some runs and not in others. The overall rate moved between 39% and 56% from one sweep to the next. An average of 49% hides that spread. The matrix shows it.

Five runs show whether an answer is stable. They do not make the rate exact.

What a run does not tell you

  • It is one model on one date. The sample used gemini-3.5-flash-lite on October 2, 2026. It says nothing about any other assistant.
  • Answers move. A reworded question, or the same question next month, can give a different result.
  • It is not a ranking. The matrix records whether a name appears, not where your brand sits against the others.
  • It is not a forecast of traffic. Being named in an answer is not a click, a visit or a sale.

Common questions

What is citation tracking?

Citation tracking asks a language model the buying questions people ask in your category and records whether it names your brand. Each question is asked 5 times, because the same question gives different answers. We report how often you are named, and how often you are featured rather than mentioned in passing.

Why five runs?

The same question gives different answers. In the sample run, 5 of 18 questions named the brand in some runs and not in others, and the overall rate ranged from 39% to 56% between sweeps. One run would have reported one of those numbers as the answer. Five runs show the spread. They do not make the rate exact.

Which models do you run?

Each run uses one named model, and its name and the date are recorded on every result. The sample on this page used gemini-3.5-flash-lite on October 2, 2026. Today we run Gemini models only. A result from one model says nothing about any other assistant, and we do not present one model as AI visibility in general.
