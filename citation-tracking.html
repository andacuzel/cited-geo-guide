How a run works

Four steps, and you only do the last one.

  1. The questions

    We use questions that do not name any brand in the category. A few mention an integration platform such as Slack or Google Workspace, because that is how buyers ask.

  2. Each asked five times

    Every question goes to one model five times, each time with no memory of the others.

  3. We record two things

    Whether you are named, and whether you appear in a heading, list label, table or bold text.

  4. You receive the report

    The questions, the marks for every try, and who is named when you are not.

Read this before you act on it

What a run can’t tell you.

  • One model, one date. A result describes one model on the day it was run.
  • Answers shift. A reworded question, or the same question next month, can give a different result.
  • It is not a ranking. It records whether a name appears, not where your brand sits against others.
  • Nothing about other assistants. A result for one says nothing about the rest.
  • No traffic forecast. Being named is not a prediction of visits or sales.
  • Named is not an endorsement. A name inside a dismissive aside counts as named.

Questions

Citation tracking, briefly.

What is citation tracking?

It is a report on whether an AI model names your brand when people ask the questions your buyers ask. We run a fixed set of questions for your category, ask each one five times, and show you when your name comes up and when it does not.

Why ask every question five times?

Because the same question can get different answers. In the sample, 5 of 18 questions named the brand in some tries and not in others. One try can mislead you. Five show the pattern.

What does named mean?

Your brand name appears in the answer. We also record whether it appears in a heading, a list label, a table or bold text, rather than only inside a sentence. A name inside a dismissive aside still counts as named. It is not an endorsement.

Can I run it myself?

A self-serve version is still to come. Today we run it for you. The question sets are also published on the Citehound MCP server, with a short protocol for running them yourself in any assistant.

Which model does it use?

The sample used gemini-3.5-flash-lite on October 2, 2026. Today we run Gemini models only. A result describes one model on one date and says nothing about any other assistant.

Is it a ranking?

No. It records whether a name appears, not where your brand sits against others. Answers shift with the wording of a question and over time, so a result is a picture of one day.
