The evidence

Shopify writes an llms.txt automatically for every store it hosts. We read two of those files by hand, Magic Spoon's and Allbirds'. The structure and phrasing were nearly identical, and neither said what the brand sells, who it is for or what sets it apart. Both pointed AI agents to Shopify's shopping skill and commerce protocol.

76% of the DTC sites in our report had an llms.txt, against 55% of the B2B sites. Two files is not every store, which is why this checker reads yours instead of assuming.

Questions

Common questions.

What is llms.txt?

llms.txt is a plain text file at the root of a site, written in markdown, that tells AI systems what the site is about and which pages matter. It is a young convention, proposed at llmstxt.org. This checker measures what the file contains. It does not measure whether any AI system reads it.

Does my platform write my llms.txt?

Some do. Shopify generates an llms.txt automatically for every store it hosts, so the file at /llms.txt may be Shopify's rather than yours. We have only confirmed that pattern for Shopify, so the checker only looks for Shopify's fingerprints.

How does the checker decide a file is a platform default?

It looks for Shopify's fingerprints in the text: references to shop.app or a Shop skill, commerce protocol and endpoint documentation, and platform marketing links. It also looks for any description of the brand. Several fingerprints with no brand description reads as a platform default. It is a pattern match and can be wrong, which is why "unclear" is a possible answer.

What should an llms.txt say about my brand?

A title with your name, a one-sentence summary of what you are and who you serve, and sections that link to the pages that matter most, such as products, pricing, policies or documentation. The Citehound MCP server's generate_llms_txt tool builds that layout from a name, a description and a list of pages.
